## 0. 协作与节奏

| 谁 | 负责 |
| --- | --- |
| lead（本机） | 实现、单测、发版链（tag/CI/pack/Release/热重载）、按验收判据自检 |
| Win10 | 独立复验：按 V 项逐条取证（真机渲染、真引擎、变异测试）、给 P1–P3、指出规划里漏掉的风险 |
| lead 派的子代理团队 | **2026-11-25 起 Win10 侧额度耗尽，独立复验改由本机派子代理做**（用户 m49942）：每个子代理只拿只读权限与一组判据，各自取证后由 lead 汇总修 P0–P2。子代理不能替代真机渲染取证，这项列为已知缺口 |

- **一批一发**：一批 = 一个主题、10 条以上改动、1–3 天。批内做完跑全量 `npm test` + 自检，才发一次 `remote_send_message`（`operationId lead-<版本>-verify-<序号>`），报告落 `X:\临时文件\win10-report-<版本>.md`。
- **报告回来一次修完**：P0–P2 全部修完再发下一批，不逐条往返；P3 可以并进下一批。
- **发布 ≠ 送验**：版本号一改一版（便于 bisect），送验按批。
- **改动登记**：每批完成时更新 CHANGELOG（过程）＋ FEATURES（能力）＋ 本文件（挪行）＋ ROADMAP（里程碑勾选）。
- 新增断言必须**做过删除式变异验证**（把修复删掉要变红），否则不算测过。

### 3.2 停手归档说明（已完成，0.118.0）

**做什么**：`docs/SCOPE.md`：能干什么（SPSS 常用过程的对齐清单 + 插件自算的过程）、不能干什么（PSPP 2.1.3 缺的 13 族 + 侧栏宽度放不下的 UI）、怎么装（`scripts/install.mjs` 一条命令 + 私有包名）、怎么验（`npm test` 计数口径）。

**为什么**：用户多次问「这些工作有什么价值」；一份能直接贴给别人看的边界说明，比继续堆功能更能回答它。

**判据**：README 顶部链到它；FEATURES 里「缺什么」不重复写第三遍。

### 3.4 同类缺陷普查（已完成，0.120.0）

**落地**：`lib/charts.js` 新增 `assertFiniteNumbers(value, where)`（递归走模型，报错带路径）与 `assertFiniteSvg(svg, kind)`（只查属性值，类目名 `NaN` 不误伤），挂在 `buildChartModel` / `renderSvg` / `composeChartGrid` 三个入口 —— 图表全部经 `renderSvg` 出图，所以这会覆盖条形/折线/散点/双标图/箱线/KM/控制图/拼版与宿主侧工厂（生存、回归诊断图）在内的所有画图路径。`client.js` 的 React SVG 由 0.119.0 的 `apIcon` 断言与 e2e 的图元清点各守一半。

**扫出的真缺陷**：KM 曲线最后一个时间点全员事件时 S 精确为 0、Greenwood 项除以 0 ⇒ `0 × ∞ = NaN`，置信带进 SVG 变成 `"NaN"` 属性、被浏览器整条丢掉（`lib/survival.js`，现塌成 `(0, 0)`）。

**判据（已验证）**：十个图型逐一构建 + 渲染的断言（`test/charts.mjs`）、S=0 的回归断言（`test/survival.mjs`）；把 `renderSvg` 的 y 缩放改成恒含 `NaN` 时，`test/charts.mjs` 多条红（`图型 bar 的 SVG 属性 y1 不是有限数："NaN"`）、e2e 第 ⑦ 条红（`api/chart` 400 + 控制台 400）。
